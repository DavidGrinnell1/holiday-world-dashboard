# Holiday World 2026 Production Dashboard

A live dashboard that pulls data from Google Sheets.

## Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and sign up (free)
2. Click "Add New Project"
3. Import this folder or connect via GitHub
4. Click Deploy

That's it! You'll get a URL like `holiday-world-dashboard.vercel.app`

## How it works

- Dashboard reads from the published Google Sheet CSV
- Auto-refreshes every 30 seconds
- Update statuses in Google Sheets, they appear in the dashboard
